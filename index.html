GUÍA RÁPIDA

Un enlace en ambos dispositivos.

Publicar en GitHub Pages

Sube los archivos de esta carpeta al repositorio, con index.html en la raíz. Activa Pages en Settings → Pages → Deploy from a branch → main → / (root). Abre el enlace HTTPS de Pages en ambos dispositivos, conectados a la misma red.

Sin configurar servicios

  1. En A, pulsa Crear invitación.
  2. En B, escanea el QR o pega el código de A.
  3. B genera una respuesta: en la página original de A, usa Escanear QR o pega esa respuesta. No abras otra pestaña para aplicar la respuesta.
  4. Comprueba el código de verificación y acepta en ambos dispositivos.

Para escanear la respuesta en el ordenador hace falta cámara. Sin ella, debes llevar el código de respuesta al ordenador mediante un método de copia que tengas disponible. GitHub Pages por sí solo no transmite ese código.

Con sala y un solo QR

La carpeta conexion-opcional contiene una ayuda de conexión para tu cuenta de Cloudflare. Tras configurarla, A crea una sala y B escanea el QR o escribe el código. El intercambio de invitación y respuesta es automático. Solo se almacenan temporalmente los datos de conexión, nunca los archivos.

Guardar archivos

En navegadores que ofrecen un selector de guardado, puedes escribir directamente en un archivo. En los demás, la app intenta usar el almacenamiento temporal del navegador. Si no está disponible, admite como máximo 64 MiB por archivo en memoria. La cuota libre y el navegador pueden imponer otros límites. No cierres la página antes de guardar los recibidos.

Privacidad y conexión

WebRTC cifra el tráfico entre navegadores. Esta app no configura servidores TURN ni STUN: intenta una conexión directa local. Algunas redes de invitados, VPN, firewalls o políticas del navegador pueden impedirla. No hay garantía de compatibilidad con cualquier navegador. Usa una red de confianza y comprueba el código de verificación.

Qué cambia frente a la versión de Windows

No hay programa Python ni BAT. Hace falta Internet para cargar GitHub Pages y para el modo sala. Una vez conectados, los archivos viajan directamente. Debes mantener las dos páginas activas; no hay vigilancia en segundo plano ni reanudación tras cerrar. La ID pertenece al navegador, no al hardware.
